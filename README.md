# The Choice Guatemala, Restaurant & Bakery

Case study | Web design and development to make reservations, view menu, and locations.

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel

## Features

- Reservation flow adapted to any third-party booking system with custom UI, and availability validation.
- Modern, elegant and interactive UI with smooth animations and transitions focused on convertion.
- Categorized menu with zoom in effect for dishes pictures.
- Locations with current day schedule detection and map url.
- Phone number format and validation based on country.
- About and legal pages with real and public information.
